RURAL DYNASTY — DOCUMENTO MESTRE

1. Identidade do projeto

Nome: Rural Dynasty
Gênero: Simulador rural 3D
Plataforma inicial: Navegadores de dispositivos móveis
Tecnologias: HTML, CSS, JavaScript e Three.js.

2. Objetivo

Desenvolver um simulador rural 3D com mundo explorável, liberdade de interação, veículos, construções funcionais, economia, personagens, atividades rurais e progressão.

3. Regra principal de desenvolvimento

- Preservar o código e as funcionalidades existentes.
- Não reconstruir o jogo do zero sem autorização.
- Não remover sistemas sem justificativa e autorização.
- Fazer alterações incrementais.
- Evitar duplicação de sistemas e funções.
- Priorizar compatibilidade com celulares.
- Testar o jogo após cada alteração importante.

4. Continuidade entre contas Claude

O GitHub é a fonte central do projeto.

Antes de começar qualquer tarefa:

1. Ler este documento.
2. Ler ARCHITECTURE.md.
3. Ler CURRENT_STATE.md.
4. Ler CHANGELOG.md.
5. Ler TODO.md e HANDOFF.md.
6. Conferir a versão mais recente do código.

Ao terminar:

1. Atualizar a documentação.
2. Registrar as alterações no CHANGELOG.md.
3. Atualizar CURRENT_STATE.md.
4. Atualizar TODO.md.
5. Preparar HANDOFF.md para a próxima conta.
6. Salvar as alterações no GitHub.

5. Regras de segurança

- Nunca sobrescrever a versão principal sem conferir as alterações.
- Nunca apagar arquivos sem autorização.
- Não inserir senhas, tokens ou credenciais no repositório.
- Não afirmar que algo funciona sem testar.
- Informar problemas e limitações encontrados.

6. Padrão de qualidade

Buscar gráficos 3D detalhados, boa iluminação, ambientes imersivos, controles responsivos, sistemas coerentes e desempenho adequado para dispositivos móveis.

7. Regra de encerramento

Toda sessão de desenvolvimento deve terminar com um resumo do que foi feito, o que falta fazer, problemas encontrados e instruções para a próxima sessão.
