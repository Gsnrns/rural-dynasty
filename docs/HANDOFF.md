RURAL DYNASTY — TRANSFERÊNCIA ENTRE SESSÕES

1. Objetivo

Este documento garante a continuidade do desenvolvimento entre diferentes contas Claude.

O GitHub é a fonte oficial do código e da documentação do projeto.

2. Instruções para iniciar uma sessão

A conta Claude que assumir o projeto deve:

1. Acessar o repositório oficial.
2. Ler README.md.
3. Ler todos os documentos da pasta docs.
4. Examinar o arquivo principal do jogo.
5. Conferir os últimos commits.
6. Identificar a última versão válida.
7. Entender as alterações anteriores antes de modificar qualquer coisa.

3. Estado da última sessão

Data: A preencher.

Conta responsável: A preencher.

Versão trabalhada: A preencher.

Objetivo da sessão: A preencher.

Alterações realizadas: A preencher.

Arquivos modificados: A preencher.

Testes realizados: A preencher.

Resultado dos testes: A preencher.

4. Pendências

Registrar aqui as tarefas que não foram concluídas e os problemas encontrados.

5. Próxima tarefa

Descrever claramente a primeira tarefa que a próxima conta deve executar.

6. Cuidados obrigatórios

- Não sobrescrever alterações de outra sessão.
- Conferir o estado do repositório antes de editar.
- Trabalhar em uma branch própria quando possível.
- Não modificar a versão principal diretamente.
- Fazer commits com mensagens claras.
- Não apagar funcionalidades existentes sem autorização.
- Não declarar sucesso sem testes.

7. Encerramento obrigatório

Antes de encerrar cada sessão:

1. Salvar as alterações no GitHub.
2. Atualizar CHANGELOG.md.
3. Atualizar CURRENT_STATE.md.
4. Atualizar TODO.md.
5. Preencher este HANDOFF.md.
6. Informar o que foi concluído e o que falta.

8. Regra de continuidade

A próxima conta deve continuar do último estado registrado, sem reiniciar o projeto ou repetir tarefas já concluídas.
